# IT Firm Management System

## Overview

The IT Firm Management System is a role-based desktop application developed using C#, Windows Forms, and SQL Server. The system streamlines IT organization operations by integrating project management, client handling, employee administration, invoice management, salary tracking, and issue management into a single platform.

## Features

### Admin Module

* User Management
* Employee Management
* Client Management
* Asset Management
* Invoice Management
* Salary Management
* Ticket Management
* Project Approval and Assignment

### Employee Module

* View and Update Profile
* View Assigned Projects
* Update Project Progress
* View Allocated Assets
* View Salary Details
* Create Support Tickets

### Client Module

* Manage Profile Information
* Submit Project Requests
* View Project Status
* View Invoices
* Make Partial Payments
* Create and Track Tickets

## Technologies Used

* C#
* Windows Forms
* SQL Server
* Visual Studio

## Database Entities

* Users
* Employees
* Clients
* Projects
* Invoices
* Assets
* Salaries
* Tickets

## System Objectives

* Simplify IT firm operations
* Improve project tracking
* Manage employee and client information
* Track invoices and payments
* Handle tickets and support requests
* Maintain salary and asset records
